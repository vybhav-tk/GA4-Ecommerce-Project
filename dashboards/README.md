# Dashboards

Power BI will be rebuilt from scratch for this portfolio version.

Store only lightweight portfolio outputs here by default:

```text
dashboards/
├── README.md
└── screenshots/
    ├── acquisition.png
    ├── funnel.png
    └── product.png
```

The archived Power BI file is intentionally not copied into this repository. If the new `.pbix` is small enough and you want to distribute it, decide explicitly whether to use normal Git, Git LFS, or a published Power BI report link.
